Overview
This project implements a Handwritten Character Recognition System using a Convolutional Neural Network (CNN) trained on the MNIST dataset.
The model is capable of recognizing handwritten digits (0–9) with high accuracy.
Objectives
Build a CNN model for image classification
Train and evaluate the model on MNIST dataset
Understand deep learning concepts in computer vision
Demonstrate real-world applications of AI
 Dataset
Dataset: MNIST
Total Images: 70,000
Training: 60,000
Testing: 10,000
Image Size: 28×28 pixels (grayscale)
Model Architecture
The CNN model includes:
Convolutional Layers
ReLU Activation Function
Max Pooling Layers
Fully Connected Layers
Softmax Output Layer
